📘 Manual de Uso — Meu Financeiro

Guia rápido com exemplos de como preencher as principais informações do sistema.

1. Tela inicial

A nova tela inicial reúne entradas, saídas, saldo, saldo projetado após pendências, reserva, saldos por banco, lançamentos recentes e contas a vencer. Use o menu lateral organizado por grupos e o botão “Ocultar valores” quando quiser mais privacidade.

2. Como lançar uma despesa

Clique em Nova Despesa. Informe data, descrição, categoria, banco, valor e vencimento. No campo Banco, escolha um banco cadastrado. Para incluir, editar ou excluir bancos, use o botão 🏦 Bancos no menu lateral. Deixe Pendente se ainda não pagou. Depois clique em Salvar lançamento.

💡 Se a despesa repetir todo mês, escolha “Sim” em Recorrente. Para contas como energia, água e internet, você também pode usar Contas Fixas.

3. Como lançar receita e salário

Para uma receita comum, clique em Nova Receita. Para seus pagamentos, use os botões Salário dia 05 e Salário dia 20. Quando o dinheiro entrar, deixe o status como Recebido.

4. Como cadastrar Contas Fixas

Entre em Contas Fixas e informe o nome, valor, dia de pagamento, categoria e banco. O campo Banco usa a lista cadastrada em 🏦 Bancos no menu lateral. O sistema soma automaticamente quanto você tem para pagar no dia 05, no dia 20 e no total.

📌 Depois de cadastrar a lista, use “Gerar pendências do mês” para criar os lançamentos daquele mês.

5. Reserva / Investimento

Use este campo quando separar dinheiro para sua reserva. Informe o valor, de qual conta saiu e o nome da reserva. Esse movimento não é tratado como uma despesa comum.

6. Dashboard e acompanhamento

  • Tela inicial / Dashboard: reúne entradas, saídas, saldo, reserva, saldos por banco, lançamentos recentes, contas a vencer, gráficos de Entradas x Saídas, Gastos por Categoria e Meta de Reserva.
  • Contas Pendentes: mostra o que ainda precisa ser pago.
  • Gerenciar / Excluir: permite corrigir ou apagar lançamentos.
  • Limites de Gastos: define limites mensais por categoria.
  • Meta da Reserva: define quanto você pretende guardar.

7. Como cadastrar Bancos / Contas

Clique em 🏦 Bancos no menu lateral. Digite o nome do banco ou da conta, por exemplo Santander, Nubank ou Caixa, e clique em + Cadastrar. O banco ficará disponível automaticamente nos novos lançamentos, Contas Fixas, Transferências e Reserva/Investimento.

🏦 Para corrigir um nome, altere-o e clique em Salvar. Para remover um banco que não será mais usado, clique em Excluir. Se ele já estiver vinculado a lançamentos, o sistema avisa antes.

7. Backup e segurança

Faça backup periodicamente, principalmente antes de usar Zerar todos os lançamentos. Se precisar, o botão Restaurar Backup recupera uma cópia salva.

8. Zerar todos os lançamentos

Use somente quando quiser começar novamente com o sistema limpo. A função pede confirmação antes de apagar. Faça um backup antes.

⚠️ Esta função apaga os lançamentos e as Contas Fixas conforme configurado na versão atual.
